# Uma Factory — 賽馬娘自動育成工具

> **原始程式作者**：[巴哈姆特 sn=5211080](https://home.gamer.com.tw/artwork.php?sn=5211080)

自動化賽馬娘育成流程的 Windows 工具，支援「おまかせ育成」全自動模式。

---

## 前提與省略說明

本腳本專注於快速進入及結束育成，省略多項手動挑選步驟，使用前請確認以下前提：

1. **育成劇本**：不挑選，直接進入下一步（開發過程使用 The Twinkle Legends 劇本）
2. **繼承父母**：不挑選，直接進入下一步
3. **技能卡**：不挑選，直接進入下一步
4. **賽程**：預設已設定好，進入時系統會自動詢問是否套用
5. **育成過程快轉**：預設已完成相關設定，育成全程不會中斷（若無設定跳過主線或未閱讀的劇情，自動育成將會中止）
6. **技能**：育成完了後直接跳過，不手動挑選
7. **繼承因子**：直接進入下一步，不重置洗因子
8. **回到主頁有新視窗**：本腳本無此機制，若有彈出視窗需手動關閉
9. **體力（TP）不足**：自動使用補充道具（道具列表第 2 項：紅蘿蔔水）
10. **活動期間額外視窗**：育成完了後可能出現獲得物品或積分等確認視窗，目前尚未支援，可能需手動處理，待更新

## 系統需求

- Windows 10 / 11
- Python 3.9+
- 遊戲視窗標題必須為 `umamusume`
- 遊戲視窗寬度固定 370px（工具會自動調整高度）

## 安裝

```bat
install.bat
```

安裝 pip 依賴並初始化 pywin32 COM 介面。

初次使用需產生場景模板：

```bat
python tools/make_templates.py
```

---

## 使用方式

### 全自動模式（推薦）

```bat
run_auto.bat
```

或直接執行：

```bash
python src/auto_main.py
```

從指定場景繼續（中途斷線恢復用）：

```bash
python src/auto_main.py --start <scene_id>
```

`<scene_id>` 定義在 `assets/scenes.json`，每個場景的 `id` 欄位即為可用值。
常見恢復點：

| scene_id | 說明 |
|----------|------|
| `nurture_main` | 育成主畫面（おまかせ按鈕前） |
| `auto_running` | 自動育成進行中（等待完成） |
| `end_01` | 育成完了確認畫面（處理結果） |

執行中按 **ESC** 可隨時優雅停止。

## 設定（config.json）

| 欄位 | 預設值 | 說明 |
|------|--------|------|
| `loop_count` | `-1` | 育成次數，`-1` 為無限循環 |
| `normal_timeout_sec` | `120` | 一般場景等待上限（秒） |
| `auto_wait_timeout_sec` | `3600` | おまかせ育成等待上限（秒） |
| `poll_interval_sec` | `1.0` | 場景偵測輪詢間隔（秒） |
| `auto_poll_interval_sec` | `30.0` | 育成中輪詢間隔（秒） |
| `click_delay_sec` | `0.5` | 點擊後延遲（秒） |
| `pre_click_delay_sec` | `1.0` | 點擊前全域延遲（秒） |

各場景可在 `assets/scenes.json` 設定個別 `timeout` 與 `wait_before_click_sec` 覆蓋全域值。

## 流程說明

全自動模式依序偵測 28 個場景，從主畫面開始到育成結束：

```
主畫面 → 育成設定（breed / 親 / support）→ TP 判斷分支
  ├─ TP 充足 → 開幕動畫跳過 → 事件設定 → 路線確認
  └─ TP 不足 → 補充 TP → 回育成設定

→ 育成主畫面 → 自動計畫 → おまかせ育成開始
→ 等待育成完成（最長 1 小時，每 2 分鐘確認一次）
→ 結果畫面（評價 / 技能 / 因子 / 記錄 / 硬幣 / 回主畫面）
```

---

## 防 Lag 機制

場景偵測超時後不立即中止，而是先嘗試偵測前一個場景：

1. 等待當前場景 → 超時 → 嘗試偵測前一個場景（同樣等待時間）
2. 若偵測到前一個場景 → 重新執行該場景點擊並繼續
3. 若前一個場景也未偵測到 → 程式中止

---

## 連線錯誤偵測

每次截圖都會掃描以下兩種錯誤：

- VPN 斷線符號（左上角）
- 「通信中にエラーが発生しました」彈窗

偵測到任一錯誤立即停止，避免程式進入無效等待。
